# Vellira

> Build consistent interfaces across Web and React Native with shared design tokens and components.

Vellira is a TypeScript-first design system for React and React Native.

It provides shared design tokens, renderer-neutral contracts, reusable interaction logic, and platform-specific component packages.

## Installation

Choose the package that matches your target platform.

### Web

```bash
pnpm add @romanbakurov/vellira-web
```

### React Native

```bash
pnpm add @romanbakurov/vellira-native
```

### Design Tokens

```bash
pnpm add @romanbakurov/vellira-tokens
```
