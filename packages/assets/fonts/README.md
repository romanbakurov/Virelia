# Vellira Sans baseline

Version 0.1 is a Latin-only production baseline derived from Kantumruy Pro.
It is not the final Vellira Sans release. Cyrillic is planned for the next stage.

Weights: ExtraLight 200, Regular 400, Medium 500, SemiBold 600.
