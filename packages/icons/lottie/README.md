# Vellira Animated Icons

99 vector Lottie JSON icons for hover and press feedback.

- Canvas: 24×24
- Frame rate: 30 fps
- Duration: 15 frames / 0.5 s
- Loop: false
- Autoplay: false
- Color: black; recolor through your Lottie theming layer

Play frames 0–14 once on hover or press. The final frame returns to the resting state.
