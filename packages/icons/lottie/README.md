# Vellira Animated Icons

99 vector Lottie JSON icons for hover and press feedback.

- Canvas: 24×24
- Frame rate: 30 fps
- Duration: 15-30 frames / 0.5-1 s
- Loop: false
- Autoplay: false
- Color: black; recolor through your Lottie theming layer

Play the full animation once on hover or press. The final frame returns to the resting state.
