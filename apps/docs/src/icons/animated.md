# Animated Icons

Animated icons provide subtle motion that communicates state changes and user interaction.

Animations are intentionally lightweight and suitable for production interfaces.

## Best For

- Hover interactions
- Expand and collapse controls
- Loading feedback
- Interactive buttons
- Navigation
- State transitions

## Design Principles

- Short duration
- Smooth easing
- Consistent motion language
- Reduced-motion friendly
