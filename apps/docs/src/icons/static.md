# Static Icons

Static icons are lightweight SVG components intended for everyday interface elements.

They render instantly, have no built-in animation, and are appropriate for almost every application surface.

## Best For

- Navigation
- Buttons
- Forms
- Menus
- Tables
- Dashboards
- Settings
- Empty states

## Features

- SVG based
- Tree-shakeable
- Accessible
- Configurable size
- Configurable color
- React and React Native support
