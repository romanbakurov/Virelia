**Build once. Stay consistent everywhere.**

Vellira is a TypeScript-first design system for React and React Native, built around shared design tokens, reusable interaction logic and platform-specific components.

This release marks the first public launch of Vellira.

## Highlights

- Shared component APIs across React and React Native
- Accessibility-minded components with documented keyboard and semantic behavior
- Shared design tokens and TypeScript contracts
- Reusable interaction logic
- Platform-specific implementations
- Tree-shakeable modular packages
- Interactive Storybook
- Documentation, Storybook examples and generated package API references
- Automated testing and release pipeline

## Components

Every component is available for both React and React Native with a consistent API:

- Button
- Checkbox
- Dropdown
- FormField
- Input
- Modal
- Portal
- Radio
- RadioGroup
- Select
- Tabs
- Tooltip
