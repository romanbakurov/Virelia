🚀 Today I'm excited to share the first public release of Vellira.

Several months ago I started working on a design system with one goal:

Build consistent interfaces across React and React Native without maintaining two completely different UI libraries.

Over time it became much more than a collection of components.

Today Vellira includes:

• shared design tokens
• consistent APIs
• accessibility-first components
• Storybook
• documentation
• automated releases
• automated testing

There is still a long roadmap ahead, but I'm excited to finally share the first public version.

I'd love to hear your feedback.

Current release includes:

✅ Button
✅ Checkbox
✅ Dropdown
✅ FormField
✅ Input
✅ Modal
✅ Portal
✅ Radio
✅ RadioGroup
✅ Select
✅ Tabs
✅ Tooltip

If you're building products for both Web and React Native, I'd love to hear your feedback.
