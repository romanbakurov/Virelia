# Release Checklist

## Before release

- [ ] CI is green
- [ ] Documentation updated
- [ ] Storybook deployed
- [ ] API docs updated
- [ ] Changelog reviewed
- [ ] Website deployed
- [ ] Version published to npm
- [ ] GitHub Release reviewed

## Launch

- [ ] Publish GitHub Release
- [ ] Publish X post
- [ ] Publish LinkedIn post
- [ ] Publish Reddit post
- [ ] Publish DEV article
- [ ] Publish Hashnode article

## After launch

- [ ] Monitor issues
- [ ] Reply to comments
- [ ] Fix reported bugs
- [ ] Plan next release
